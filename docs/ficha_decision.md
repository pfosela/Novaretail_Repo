# Ficha de decisión (sesión 5)

Una ficha por decisión que soporta el análisis. Copiad el bloque tantas veces como haga falta.

| Campo | Contenido |
|---|---|
| Decisión | p. ej. "Qué pedidos online requieren intervención hoy" |
| Nivel | Operativa / Táctica / Estratégica |
| Responsable | p. ej. jefe de turno del almacén |
| Frecuencia | diaria / semanal / trimestral |
| Pregunta de negocio | |
| Datos necesarios | datasets y campos |
| KPI / señal | leading o lagging, umbral |
| Acción que permite | |
| Coste de equivocarse | falso positivo vs. falso negativo |
| Calidad mínima exigida | reglas del contrato que deben cumplirse |
